# Домашнє Завдання 39: Stateful vs Stateless компоненти в React

Цей проект створено за допомогою Vite + React для вивчення основних концепцій розробки компонентів у React.

## 📝 Опис проекту
У проекті реалізовано:
1. **StatelessComponent** — безстановий (презентаційний) функціональний компонент, який лише приймає пропси (властивості) та відповідає за відображення даних.
2. **StatefulComponent** — функціональний компонент зі станом, який використовує хук `useState` для збереження локального стану (лічильника) та керування ним.
3. **ClassComponent** (Додаткове завдання) — класовий компонент, який дублює функціонал `StatefulComponent`, зберігаючи стан у `this.state` та змінюючи його через `this.setState`.

## 🆚 Порівняння: Класові vs Функціональні (з хуками) компоненти

1. **Зручність розробки**
   - *Функціональні*: Значно зручніші завдяки хукам (`useState`, `useEffect`). Код коротший, не потрібно думати про прив'язку контексту (`bind(this)`).
   - *Класові*: Вимагають більше "бойлерплейт" коду (конструктор, `super(props)`, `this`).

2. **Читабельність коду**
   - *Функціональні*: Висока читабельність. Логіка не розкидана по різних методах життєвого циклу.
   - *Класові*: Читабельність знижується зі зростанням компонента через потребу звертатися до `this.state` та `this.props` на кожному кроці.

3. **Використання життєвого циклу**
   - *Функціональні*: Хук `useEffect` дозволяє об'єднати логіку монтування, оновлення та демонтування (componentDidMount, componentDidUpdate, componentWillUnmount) в одному місці за змістом.
   - *Класові*: Потребують розділення логіки між кількома методами життєвого циклу, що іноді призводить до дублювання коду (наприклад, запит на сервер у `componentDidMount` та `componentDidUpdate`).

## 🚀 Інструкція зі встановлення та запуску

1. Клонуйте репозиторій на свій комп'ютер.
2. Відкрийте термінал у папці проекту (`my-react-app`).
3. Встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```
5. Відкрийте браузер за адресою `http://localhost:5173`.
